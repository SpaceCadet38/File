# Nếp Stay

Landing page tiếng Việt cho concept homestay Nếp Stay, xây dựng bằng Vue 3, Vite và Lucide. Trang có bộ lọc điểm đến và số khách, thông tin tiện nghi, cùng giá dự kiến theo số đêm.

## Chạy dự án

Yêu cầu Node.js 22 trở lên.

```sh
npm ci
npm run dev
```

Dùng `npm run build` để tạo bản tĩnh trong `dist/`. Dùng `npm run preview` để xem bản build.

## Dữ liệu

Thông tin các căn mẫu nằm trong `src/stays.js`. Ảnh và giá dùng để minh họa. Trang chưa kết nối với hệ thống đặt phòng hoặc thanh toán.
